
# Music Portfolio

A simple, responsive digital portfolio for music and video projects.

## Features
- Three navigation tabs: Music, Videos, About
- Album artwork and streaming links
- Embedded YouTube videos
- Artist biography and contact information
- Responsive mobile layout
- Built with HTML, CSS, and JavaScript

## Getting Started

1. Download or clone this repository.
2. Edit index.html with your own content.
3. Replace placeholder images and video IDs.
4. Customize colors and fonts in style.css.
5. Upload the files to GitHub.

## GitHub Pages

Go to:
Settings → Pages

Under Build and deployment:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Save. Your portfolio will be published at:

https://YOUR-USERNAME.github.io/
